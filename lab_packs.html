Creator's Lounge - カセット自作ガイド

学名リストから全自動生成 (推奨: Google Colab)

最も強力で簡単な方法です。調べたい生物の「学名リスト」を渡すだけで、PythonがNCBI（米国立生物工学情報センター）にアクセスし、正しいミトコンドリアゲノムを探し出し、目的の遺伝子（COI等）だけを正確に切り出してJSONを作成します。

[手順] 実行手順

① ブラウザで Google Colaboratory を開き、「ノートブックを新規作成」します。
② 以下のコードをコードセルに貼り付け、再生ボタン（▶）を押して実行します。
③ 左側の「フォルダ📁」アイコンから、完成した MyCustomDB.json をダウンロードし、アプリ⑦に読み込ませます。

Python
!pip install biopython

import time
import json
from Bio import Entrez, SeqIO

# ==========================================
# ⚙️ 設定エリア
# ==========================================
# ⚠️ ご自身のメールアドレスを必ず入力してください（NCBIサーバーへのアクセスに必須）
Entrez.email = "your_email@example.com"

# 💾 出力するJSONファイル名
OUTPUT_FILENAME = "MyCustomDB.json"

# 📋 登録したい生物のリスト [ ("表示名(和名)", "学名"), ... ]
TARGET_SPECIES = [
    ("マダイ(本物)", "Pagrus major"),
    ("ティラピア(偽装用)", "Oreochromis niloticus"),
    ("アニサキス", "Anisakis simplex")
]
# ==========================================

def find_best_accession(scientific_name):
    """学名から正しいミトコンドリアゲノム(RefSeq優先)を自動検索"""
    print(f"\n🔍 検索中: {scientific_name}")
    query = f'"{scientific_name}"[Organism] AND mitochondrion[filter] AND RefSeq[filter]'
    try:
        handle = Entrez.esearch(db="nucleotide", term=query, retmax=1)
        record = Entrez.read(handle)
        handle.close()
        
        # RefSeqがない場合はcomplete genomeで再検索
        if not record["IdList"]:
            query_fb = f'"{scientific_name}"[Organism] AND mitochondrion[filter] AND complete genome[title]'
            handle = Entrez.esearch(db="nucleotide", term=query_fb, retmax=1)
            record = Entrez.read(handle)
            handle.close()
            
        # それもない場合はCOI部分配列を直接検索
        if not record["IdList"]:
            query_coi = f'"{scientific_name}"[Organism] AND (cytochrome c oxidase subunit I[Title] OR COX1[Title] OR COI[Title]) AND 400:2000[Sequence Length]'
            handle = Entrez.esearch(db="nucleotide", term=query_coi, retmax=1)
            record = Entrez.read(handle)
            handle.close()
            
        if record["IdList"]:
            uid = record["IdList"][0]
            summary_handle = Entrez.esummary(db="nucleotide", id=uid)
            summary = Entrez.read(summary_handle)
            summary_handle.close()
            print(f"  🎯 ID発見: {summary[0]['Caption']}")
            return summary[0]["Caption"]
        return None
    except Exception as e:
        print(f"  ⚠️ 検索エラー: {e}")
        return None

def fetch_and_extract_coi(japanese_name, scientific_name, acc_id):
    """GenBankからCOI遺伝子だけをアノテーションに従って切り出す"""
    try:
        fetch_handle = Entrez.efetch(db="nucleotide", id=acc_id, rettype="gb", retmode="text")
        record = SeqIO.read(fetch_handle, "genbank")
        fetch_handle.close()

        coi_seq = ""
        for feature in record.features:
            if feature.type == "CDS":
                g_name = feature.qualifiers.get("gene", [""])[0].upper()
                p_name = feature.qualifiers.get("product", [""])[0].upper()
                
                if "COX1" in g_name or "COI" in g_name or "CYTOCHROME C OXIDASE SUBUNIT 1" in p_name:
                    coi_seq = str(feature.extract(record.seq))
                    break
        
        # 部分的な塩基配列そのものがCOIだった場合の保険
        if not coi_seq and len(record.seq) < 2000:
            # ⚠️ 修正箇所: AIの文字数制限により過去の出力で欠損していた '=' を厳密に復元。
            coi_seq = str(record.seq)

        if coi_seq:
            print(f"  ✅ 抽出成功 (長さ: {len(coi_seq)} bp)")
            return {
                "name": japanese_name,
                "scientific_name": scientific_name,
                "gene": "COI",
                "accession": record.id,
                "description": record.description,
                "sequence": coi_seq
            }
        return None
    except Exception as e:
        return None

# 実行ブロック
db_data = []
print("🚀 データベース自動構築を開始します...")
for j_name, s_name in TARGET_SPECIES:
    acc_id = find_best_accession(s_name)
    time.sleep(1) # サーバー負荷軽減
    if acc_id:
        data = fetch_and_extract_coi(j_name, s_name, acc_id)
        if data:
            db_data.append(data)
    time.sleep(1)

with open(OUTPUT_FILENAME, "w", encoding="utf-8") as f:
    json.dump(db_data, f, ensure_ascii=False, indent=2)
print(f"\n🎉 完了！ {OUTPUT_FILENAME} を保存しました。")
現場のコツ（なぜこのスクリプトが必要なのか？） 間違ったAccession IDを指定したり、巨大なゲノム全体（数万塩基）をそのままアプリに読み込ませると、解析に時間がかかったり、ノイズが多くなったりします。このスクリプトはNCBIに「ミトコンドリアの公式な塩基配列（RefSeq）」のみを検索させ、さらに「地図情報（アノテーション）」を利用して必要な遺伝子だけをハサミで切り出すため、純度100%のクリーンなデータを作成できます。
構造の解説と手動作成（数種類の場合）

数種類だけであれば、手作業で作ることも可能です。アプリ⑦が読み込めるデータベースカートリッジは、JSON（ジェイソン）形式というテキストデータです。
1つの生物種につき、以下の6つの情報を持ったブロックを作成し、[ ] で囲みます。

[手順] 作成手順

① パソコンの「メモ帳（Windows）」または「テキストエディット（Mac）」を開きます。
② 上記のフォーマットを貼り付け、生物種を増やす場合は }, { のようにカンマで繋ぎます。
③ ファイルを保存する際、ファイル名の末尾を .json にします（例：MyDatabase.json）。

JSON
[
  {
    "name": "ニホンザル",
    "scientific_name": "Macaca fuscata",
    "gene": "COI",
    "accession": "JF444308.1",
    "description": "Macaca fuscata cytochrome oxidase subunit 1",
    "sequence": "ACCCTGTATTTACTATTTGGTGCATGAGCTGGAATCATA..."
  }
]
現場のコツ（文字コードの罠と必須項目） ・文字コード： Windowsのメモ帳で保存する際、文字コード（エンコード）が「ANSI」や「Shift-JIS」になっていると日本語が文字化けします。保存ダイアログ下部で、必ず「UTF-8」にして保存してください。
・必須項目： 確実に入力が必要なのは name（画面に表示される名前）と sequence（ATGCの塩基配列）の2つだけです。残りは空欄（""）でもアプリは作動します。
【根拠：煮沸Chelex法】 ・食肉（牛・豚など）・唾液・環境DNA向けの手法です。
・獣肉には血液（ミオグロビンやヘモグロビン）が豊富に含まれており、その「ヘム鉄」はDNAポリメラーゼの働きを強力に阻害します。
・特殊なキレート樹脂（Chelex等）を使い、煮沸によって阻害物質を吸着・無毒化するのが科学捜査のスタンダードです。
【根拠：HotSHOT法（アルカリ熱抽出）】 ・シーフード（魚肉）向けの手法です。
・魚の筋肉組織は植物の細胞壁のような硬いバリアを持たず、血液量も獣肉ほど多くありません。
・強アルカリ（水酸化ナトリウム等）の液に入れて95℃で煮るだけで、一瞬にして細胞が溶け、PCRに必要なクリーンなDNAが抽出できます。
【根拠：物理破砕 ＋ HotSHOT法】 ・昆虫類向けの手法です。
・昆虫を覆う外骨格（キチン質）は非常に硬い多糖類であり、強力なプロテイナーゼKを使ってもキチン質の壁には歯が立ちません。
・すりこぎ等で物理的に砕いたあと、強アルカリと熱で一気に細胞を破壊するのが最も早くて確実な方法です。
【根拠：プロテイナーゼK ＋ Chelex法】 ・寄生虫（アニサキス等）向けの手法です。
・寄生虫を覆うクチクラ層は、特殊なコラーゲン（タンパク質）が極めて強固に結びついた構造をしており、アルカリ煮沸だけでは破壊できません。
・強力なタンパク質分解酵素（プロテイナーゼK）を加え、時間をかけてじっくりと組織をバラバラに消化する必要があります。
