# Bio-Edu Suite

## 概要 (Overview)
**Bio-Edu Suite** は、高等学校および大学の生物学・バイオインフォマティクス実習のために開発された、**ブラウザだけで完結する教育用ウェブアプリケーション群（v38.2）**です。

DNAの抽出・PCR反応液の最適化から、電気泳動・制限酵素消化シミュレーション、サンガー法シーケンス波形編集、多重塩基配列アライメント、相同性検索（BLAST）、系統樹推定（UPGMA/NJ/MP/ML）、幾何学的形態測定（EFA/GPA/PCA）、分子×形態の統合分類・Mantel検定、統計遺伝学（G×E相互作用・ダイアレル交配分析）、そしてセントラルドグマとタンパク質の3D立体構造解析まで、現代の生物科学における一連のWet/Dry探究パイプラインをシームレスに体験できます。

サーバー構築やPython環境のインストールは一切不要。Chromebook、iPad、Windows、MacなどのブラウザでHTMLを開くだけで、本格的なバイオインフォマティクス実習を即座に開始できます。

## 基本哲学 (Our Philosophy)
1. **「なぜ？」を必ず示す (Rationale System)**
   操作のブラックボックス化を防ぐため、熱力学的根拠やアルゴリズムの数理的背景を「現場のコツ（`.bench-tip`）」やオンデマンドな解説ポップオーバー（`[?]` ボタン）としてUI随所に提示します。また、簡易な偽装計算（モック）を排し、裏側では本物の数学・確率モデルを駆動させています。
2. **手動バケツリレーと冗長性の教育的価値 (Pedagogical Bucket Relay & Redundancy)**
   解析アプリ間のブラックボックスな自動データ受け渡しを排し、生徒自らの手で解析結果（FASTA/TSV/JSON/Newick等）を「クリップボードへコピー＆ペースト」または「ローカルファイル保存＆次アプリへドラッグ＆ドロップ」して持ち寄る「手動バケツリレー」を徹底。データの構造と変換プロセスを体感させるとともに、すべてのデータ出力箇所に「コピーボタン」と「ローカルファイル保存ボタン」をペア配備し、クリップボード消失時にも絶対に授業を止めない冗長性を備えています。
3. **プロツールへの架け橋 (Bridge to Professional)**
   ブラウザ内でMEGA、MAFFT、ImageJ、PyMOL、R（agricolae等）相当のアルゴリズムを忠実にエミュレートして基礎を学んだ後、研究現場で使われるプロ向け専門ソフトウェアへステップアップできるよう誘導する足場掛け（Scaffolding）を各アプリ末尾に備えています。
4. **日本学術会議（2025年版）用語規格への完全準拠 (Academic Standard)**
   日本学術会議の公式報告『高等学校の生物教育における重要用語の選定について（2025年版）』に完全準拠しています。
   - **突然変異 (`mutation`: 遺伝情報が変化するプロセス)** と **変異 (`variation`: 集団内の形質差・多様性)** と **突然変異体 (`mutant`)** の厳格な区別
   - 優性・劣性に代わる **顕性・潜性**（顕性効果・顕性分散を含む）への完全統一
   - 古細菌に代わる **アーキア** の採用
   - **自然免疫** と **獲得免疫（適応免疫）** の協調の重視
   - 対象分子・配列の明記（**DNA**、**mRNA**、**タンパク質**、**塩基配列**、**アミノ酸配列**）および常用漢字外の平仮名表記（**血しょう**、**かく乱**、**胚のう** 等）

## 学校現場特化の「ローカル要塞」＆オンデマンド同期設計 (Classroom-Ready Architecture / v38.2)
学校のICT実習における「ログインできない」「通信制限やWi-Fi不調で画面が固まる」「他の生徒のデータで勝手に上書きされる」といったトラブルを物理的に根絶するため、**ローカル要塞（Local Fortress）アーキテクチャ**と**Kahoot方式の完全手動（オンデマンド）クラウド同期**を統合しています。

* **ローカル要塞化＆同一セッション内ステート完全保持 (Local Fortress & Zero Data Loss):**
  日常の作業保存およびアプリ間の画面遷移は、外部ネットワーク通信を一切介さず、100%端末内のローカルストレージ領域（`localStorage` / `sessionStorage` / 大容量波形・DB用の `IndexedDB`）への即時自動保存とハイドレーション（復元）で完結します。オフライン環境でもすべての主要解析が高速に動作します。
* **ゼロ・ログイン ＆ Kahoot方式ルーム接続 (Zero-Login & Privacy-First):**
  Googleアカウントやメールアドレス、パスワードの登録は一切不要。Firebase匿名認証を基盤とし、「ルームコード（例: `BIO-101`）」と「参加者ID（班番号 `Team-A` または出席番号 `No-15`）」を入力するだけで入室でき、生徒の個人情報を一切収集しません。
* **完全手動（オンデマンド）クラウド同期 (On-Demand Cloud Sync / v38.0):**
  バックグラウンドでの意図しない自動送受信や上書き事故を防ぐため、クラウド（Firestore）との通信は、設定モーダル内の **「現在の作業をクラウドに保存」「クラウドから作業を復元」ボタンを手動でクリックした時のみ** 実行されます。学校の実習端末で保存した作業を、自宅のPCやタブレットから同一コードで安全に引き継ぐことができます。
* **隠れ教師モード ＆ 課題プリセット一発配信 (Secret Teacher Mode & Single Source of Truth):**
  教員が参加者IDの先頭に `TEACHER`（例: `TEACHER` や `TEACHER-01`）と入力して入室すると、教員専用の課題発行パネルが解放されます。教員端末上の教材データを課題コード（例: `TASK-ALX1`）としてクラウド正本（`/master_tasks`）へ一発登録でき、生徒は常設の課題読込窓にコードを入力して「読込」を押すだけで、`.ab1` 波形バイナリを含む全教材データを手元端末へ即座に展開できます。
* **ロール別スマート初期化 ＆ ゾンビ復活遮断防壁:**
  「データを初期化」実行時、生徒端末ではローカルデータの消去と自身のクラウドスナップショット削除（ルーム退出）のみが行われ、他班のデータや教材原本は完全保護されます。一方、教員ロール（`TEACHER-*`）で初期化した場合は、該当ルーム全体のクラウドデータを一括パージしてルームを安全に解散できます。

## UI/UX デザイン規格 (v38.2)
* **絵文字フリー＆シャープなインラインSVG体系:** OSやブラウザによる表示崩れを防ぐため装飾絵文字を全廃し、フェーズカラーやボタン意味論（前進＝青、完了・保存＝緑、破壊・警告＝赤、補助・コピー＝白/グレー）に完全同期するインラインSVGアイコンを採用しています。
* **洗練されたグローバル・ドロワー (Peg Menu):** PC表示（`1025px` 以上）では左端 `60px` の付箋型メニューからホバーまたはピン留めで `280px` に展開。タブレット縦・スマートフォン表示（`1024px` 以下）では画面外へ完全隠蔽し、画面領域を最大限に活用します。
* **PWA・ネイティブアプリライクな操作感:** View Transitions APIによる滑らかな画面遷移、厳格なタッチターゲット（最小44px / モバイル48px）の確保、ラバーバンド（バウンス）抑制、長押しコンテキストメニュー制御、数値キーパッド自動呼出（`inputmode`）、およびService Workerによる非侵入型アップデート通知（作業状態を維持したまま即時更新）を標準搭載しています。

## 収録アプリケーション (v38.2 全14アプリ ＋ 教材パック)

デジタル野帳（LIMS）であるダッシュボードを起点に、全6フェーズ＋拡張パッケージで構成されています。

### PHASE 1: 収集・ハブ (LIMS)
* **Investigation Dashboard** (`index.html`)
  各アプリへのハブとなる階層型デジタル野帳（Multi-file Sample Hub）。1サンプルにつき複数のサンガー波形（`.ab1`）、塩基配列・アミノ酸配列（遺伝子マーカータグ付き）、形態画像、および生息場所・環境メタデータを一元管理します。複数マーカー混在時のスマート・ディスパッチ（選択送信）、Phase 4/5 共通の環境TSV出力、および全サンプルのJSONローカルバックアップ機能を備えています。

### PHASE 2: DNAラボ (Wet & Dry Molecular Lab)
* **① PCR Master Mix Studio** (`1_Master_Mix_Studio.html`)
  反応液量・試薬濃度の精密計算、ピペッティング手順の可視化、およびスケールダウン最適化シミュレーター。
* **② Thermal Cycler Simulator** (`2_Thermal_Cycler_Simulator.html`)
  DNAポリメラーゼ特性・プライマー $T_m$ 値・増幅長に基づく熱プロファイル設計（レガシーテンキー／タッチドラッグ／PC一括設定の3モード切替対応）と論理的トラブルシューティング。
* **③ Virtual PCR & RFLP** (`3_Virtual_PCR_RFLP.html`)
  アガロースゲル電気泳動バンドシミュレーションと、制限酵素によるDNA消化断片長多型（RFLP）解析。
* **④ Sanger Trace Editor** (`4_Sanger_Trace_Editor.html`)
  ABI/SCF（`.ab1`）サンガー波形データの可視化、Reverse Complement変換、ノイズ手動トリミング・ベースコール編集（`IndexedDB` 大容量永続化＆可変スピード・エッジオートスクロール対応）。
* **⑤ DNA Alignment Studio** (`5_DNA_Alignment_Studio.html`)
  複数塩基配列の多重アライメント、コンセンサス配列導出、トリミング、および熱力学パラメータに基づくプライマー設計を行うパイプライン・ハブ。
* **⑥ Alignment Print Studio** (`6_Alignment_Print_Studio.html`)
  論文・探究レポート提出用の高精細アライメント図版レイアウト・出力スタジオ。
* **⑦ Virtual BLAST Explorer** (`7_Virtual_BLAST_Explorer.html`)
  ローカルWeb Workerによる「オフライン・ファーストモード（カスタムDBカセット対応）」と、NCBI QBLAST REST APIを直接叩く「オンライン・探究モード」をシームレスに切り替え可能なハイブリッド相同性検索ツール。スコアリングマトリクスやE-valueの数理的意義を視覚的に学べます。
* **⑧ Phylogenetic Tree Builder** (`8_Phylogenetic_Tree_Builder.html`)
  UPGMA法、近隣結合法（NJ法）、最大節約法（MP法：Fitchアルゴリズム）、最尤法（ML法：JC69モデル）の系統樹探索およびブートストラップ解析をWeb Workerで並列処理する分子系統樹推定ツール。過去の解析条件・距離行列・系統樹をワンクリックで呼び戻せる「解析ログ・タイムマシン復元機能」を搭載。

### PHASE 3: 形態ラボ (Geometric Morphometrics)
* **⑨ Morphometrics Studio** (`9_Morphometrics_Studio.html`)
  生物画像から輪郭・ランドマークを抽出し、Kuhl & Giardina (1982) の楕円フーリエ解析（EFA）および一般化プロクラステス解析（GPA）、主成分分析（PCA）による幾何学的形態測定を実施。

### PHASE 4: 統合検証ルーム (Integrative Taxonomy & Coevolution)
* **⑩ Integrative Taxonomy Studio** (`10_integrative_taxonomy_studio.html`)
  分子系統樹と形態デンドログラム（または宿主と寄生虫の系統樹）を対比させるタングルグラムおよびPCA空間モーフィング検証ツール。ダッシュボードから出力した環境TSV（または対応表）を読み込み、生息環境ごとの動的カラーマッピングと学術凡例描画を自動で行います。
* **⑪ Comparative Variant Analyzer** (`11_Comparative_Variant_Analyzer.html`)
  遺伝的距離（突然変異の蓄積）と形態的距離（表現型の変異）の相関をMantel検定（順列検定）によって統計的に比較検証。共通の `Sample_ID` に基づく内部結合（Inner Join）と欠損サンプルの安全な自動除外機能を備えています。

### PHASE 5: 統計遺伝学 (Quantitative & Statistical Genetics)
* **⑫ Statistical Genetics Lab** (`12_Statistical_Genetics_Lab.html`)
  2つの高度な量的遺伝学解析モードを搭載した統計遺伝学スタジオ。
  1. **G×E 相互作用解析モード**: 環境データと形態測定値を結合し、AMMIバイプロット、反応規範（Reaction Norm）、二元配置分散分析（ANOVA）を通じて遺伝×環境相互作用と適応度の逆転を解析。
  2. **ダイアレル交配分析（Diallel Analysis）モード**: Griffingの第2法（固定効果モデル）に基づき、親系統およびF1後代の形質値から **一般組合せ能力（GCA：相加的効果）**、**特定組合せ能力（SCA：顕性効果）**、**高親ヘテロシス（雑種強勢）**、およびダイアレル分散分析表（Diallel ANOVA）を算出・可視化します。

### PHASE 6: 構造生物学 (Structural Biology & Central Dogma)
* **⑬ Central Dogma Simulator** (`13_Central_Dogma_Simulator.html`)
  DNAからmRNAへの転写、スプライシング、リボソームでの翻訳（コドン表連動）シミュレーション、および突然変異（置換・挿入・欠失）に伴うアミノ酸物性急変の検出。
* **⑭ Protein Structure Explorer** (`14_Protein_Structure_Explorer.html`)
  PDB実測構造およびAlphaFold DBと連動した3D立体構造ビューア。ワンクリックで「半透明の分子表面（外殻）」と「不透明なリボンモデル（内部骨格）」を重ねて可視化する複合描画（Trans-Surface Standard）を備え、ヘム等のリガンドや突然変異部位の空間的配置・周辺5Å相互作用・疎水性（ハイドロパシー）を直感的に探究できます。

## EXTRA: Bio-Edu Lab Packs (実践教材パック)
実際のWet実験（DNA抽出・PCR・制限酵素処理・骨格標本観察）と本スイートのDry解析を有機的に結びつけた実践的探究パッケージです（`lab_packs.html`）。直感的な2D画像デジタイザ（部位選択時の自動全画面化＆点滅数値のワンクリックコピー・自動復帰機能付き）を内蔵しています。

* **1-A. 食肉偽装の真実を暴け**（標的: ミトコンドリアDNA *Cytb* 遺伝子） - ミンチ肉に隠された異種DNAをPCR-RFLPと塩基配列解読で特定。
* **1-B. 鎌状赤血球症のHbと脊椎動物の進化**（標的: *HBB* 遺伝子・グロビンファミリー） - 1塩基の突然変異によるタンパク質立体構造の変化（ミクロ）と分子進化（マクロ）を解明。
* **2-A. フライドチキンから辿る脊椎動物の前肢**（対象: 前肢骨格・発生関連遺伝子） - 骨格標本計測と遺伝子データを突き合わせ、相同器官と適応放散を検証。
* **2-B. 見た目のそっくりは本当の親戚か？**（対象: 頭骨形態・核/ミトコンドリア遺伝子） - タヌキ、アライグマ、ハクビシン等の頭骨形態測定と分子系統樹の不一致から収斂進化を証明。
* **3-A. アニサキス科線虫の同胞種鑑別**（標的: 核DNA ITS領域） - 形態で区別困難な同胞種をPCR-RFLPと形態多変量解析で鑑別し、宿主転換と共進化を追跡。
* **3-B. 人類の進化と自身のルーツ探究**（対象: ミトコンドリアDNA・頭蓋顔面形態データ） - 化石人類・類人猿との形態計測比較と分子系統解析から、脳拡大と顔面平坦化の進化を検証。

## テクノロジー (Tech Stack)
* **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+), Progressive Web App (`manifest.json`, `sw.js`, `js/pwa_updater.js`)
* **Zero Server Dependencies:** すべての基本計算・描画がブラウザ内部で完結。
* **Local Fortress & On-Demand Cloud:** `localStorage`, `sessionStorage`, `IndexedDB` (`BioEdu_IndexedDB`), Firebase (Authentication 匿名認証, Cloud Firestore 手動オンデマンド同期)
* **Visualization & Math:** D3.js (v7), 3Dmol.js, Canvas 2D API
* **Bio Math Engine (`lib/bio_math_engine.js`):** 楕円フーリエ変換、一般化プロクラステス重ね合わせ（GPA）、NIPALS法による主成分分析（PCA）、Lance-Williams距離更新、Mantel順列検定、AMMIモデル、Griffing Method 2 ダイアレル分析等をブラウザ上で高速実行。
* **Phylo Worker (`phylo_worker.js`):** 最大節約法（Fitchアルゴリズム）や最尤法（JC69モデル尤度計算）等の重負荷な系統樹探索・ブートストラップ計算をWeb Workerでマルチスレッド並列処理。

## 使い方 (How to Use)
1. 本リポジトリのファイルをダウンロード（または `git clone`）して展開します。
2. `index.html`（Investigation Dashboard）をモダンブラウザ（Chrome, Safari, Edge等）で開きます（ローカルサーバー環境またはホスティング環境推奨）。
3. そのままオフライン（ローカル自動保存モード）ですべてのアプリとデータ連携を利用できます。
4. 授業で課題プリセットを配布・受信する場合や、別端末へ作業を引き継ぐ場合は、ヘッダー右上の「ルーム・同期設定」ボタンから課題コードの読込、またはルーム入室と手動クラウド保存・復元を行ってください。
